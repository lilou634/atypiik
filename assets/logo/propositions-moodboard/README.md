- `piste-N.svg` : couleur de la piste, fond transparent
- `piste-N-bordeaux.svg` : version bordeaux (#6d1a2a), fond transparent
- `piste-N-transparent.png` et `piste-N-bordeaux-transparent.png` : PNG 1600 px, fond transparent
- `planche.png` : les huit pistes sur leur fond de couleur
