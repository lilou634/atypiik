# Photos des œuvres

Déposez ici une photo par œuvre (JPG, environ 1200 px de large, format portrait 3:4 de préférence),
puis déclarez-la dans `js/photos.js` :

```js
const PHOTOS = {
  a1: "assets/photos/a1.jpg",
  a13: "assets/photos/veste-atelier.jpg",
};
```

Les identifiants (`a1`, `a13`…) sont listés dans `js/data.js`.
